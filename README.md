## 1. Реализация умных указателей

В работе реализованы два умных указателя: `UnqPtr` и `ShrdPtr`. `UnqPtr` обеспечивает единоличное владение объектом, а `ShrdPtr` позволяет нескольким указателям совместно обращаться к объекту через `UnqPtr`. Для подсчёта количества `ShrdPtr` используется счётчик ссылок. Также реализована поддержка массивов и преобразования типов при наследовании.

## 2. Тестирование

Для проверки корректности работы написаны функциональные тесты, охватывающие создание, копирование, перемещение указателей, присваивание, работу с массивами, преобразование типов и контейнер `Sequence`. Всего успешно пройдены 43 теста. Дополнительно проведена проверка с помощью AddressSanitizer.

Для поиска проблем с памятью использовался Dr. Memory. Он обнаружил возможную утечку в 24 байта, связанную с системными библиотеками Windows. Подтверждённой утечки памяти в собственном коде по результатам проверки не установлено.

## 3. Сравнение производительности

Проведены замеры времени работы обычных указателей и `UnqPtr`, а также контейнеров на их основе. Измерения выполнялись для разных размеров входных данных. Результаты замеров сохранены в таблице `benchmark.txt`.

При небольших объёмах данных существенной разницы во времени работы не наблюдается. На больших объёмах результаты различаются в зависимости от теста: `UnqPtr` в отдельных случаях работает немного медленнее обычных указателей.

## 4. Заключение

В ходе работы реализованы умные указатели с единоличным и совместным владением, написаны функциональные тесты и проведено сравнение производительности. Корректность основных операций проверена автоматическими тестами и санитайзерами.
