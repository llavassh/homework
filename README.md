## 1. Реализация умных указателей

Реализованы два умных указателя: `UnqPtr` и `ShrdPtr`. Первый обеспечивает единоличное владение объектом, второй позволяет нескольким указателям совместно обращаться к объекту через `UnqPtr` с использованием счётчика ссылок. Реализованы перемещение указателей, преобразование типов при наследовании и поддержка массивов для `UnqPtr`.

Также реализован контейнер `Sequence`, использующий `UnqPtr` для хранения элементов.

## 2. Тестирование

Написаны функциональные тесты для проверки создания, перемещения, копирования и присваивания указателей, работы с массивами, преобразования типов и контейнера `Sequence`. Успешно пройдены 43 теста.

Дополнительно выполнена проверка с помощью AddressSanitizer и UndefinedBehaviorSanitizer. Для анализа использования памяти использовался Dr. Memory. Он сообщил о возможной утечке в 24 байта, связанной с системными библиотеками Windows. Подтверждённая утечка в собственном коде не установлена.

## 3. Сравнение производительности

Проведены замеры времени работы обычных указателей и `UnqPtr`, а также контейнеров `DynamicArray` и `Sequence`. Для каждого размера входных данных выполнялось несколько повторов, после чего выбиралось медианное время. Результаты сохранены в файле `benchmark.txt`.

При работе с отдельными указателями на больших объёмах `UnqPtr` показал несколько большее время выполнения. При сравнении контейнеров результаты зависели от размера данных: в некоторых случаях быстрее работал `Sequence`, в других `DynamicArray`. Полученные результаты не показывают однозначного преимущества одного варианта во всех тестах.

## 4. Заключение

В ходе работы реализованы умные указатели с единоличным и совместным владением, контейнер на их основе, функциональные тесты и сравнение производительности. Основные операции проверены автоматическими тестами и санитайзерами.
